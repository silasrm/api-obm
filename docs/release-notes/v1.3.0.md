## CMED Conformidade de Preços

Integração da Conformidade de Preços da CMED (Câmara de Regulação do Mercado de Medicamentos) com a ontologia OBM, permitindo consultar preços regulados pela ANVISA junto aos dados ontológicos dos medicamentos.

### Funcionalidades

- **Tabela CMED independente** — `tb_cmed_conformidade` com versionamento por `nu_sanreg + dt_referencia` (histórico de preços)
- **Endpoints CMED** — listagem com filtros (nome, registro, EAN, tarja, tipo, regime), busca por ID, Registro Sanitário, EAN e histórico de preços
- **JOIN AMPP+CMED** — `GET /api/v1/ampp/:id/cmed` retorna dados ontológicos + preço regulado em uma única chamada
- **Cache Redis** — JOIN AMPP+CMED com cache Redis e TTL configurável. Graceful degradation: API funciona sem Redis (sem cache, query direta no PostgreSQL)
- **CLI de importação CMED** — `cmd/cmed_import/` com parse XLSX, `--header-row` configurável (default 42), UPSERT batch, invalidação de cache e reindexação Meilisearch
- **Busca global CMED** — Index `obm_cmed` no Meilisearch com filtros por `tarja` e `registro` na busca global
- **Redis no Docker Compose** — Novo serviço Redis com healthcheck, configuração via variáveis de ambiente

### Novos Endpoints

| Método | Rota | Descrição |
|--------|------|-----------|
| GET | `/api/v1/cmed` | Listar registros CMED com filtros e paginação |
| GET | `/api/v1/cmed/:id` | Buscar CMED por ID |
| GET | `/api/v1/cmed/registro/:registro` | Buscar CMED por Registro Sanitário |
| GET | `/api/v1/cmed/ean/:ean` | Buscar CMED por código EAN |
| GET | `/api/v1/cmed/:id/historico` | Histórico de preços de um registro CMED |
| GET | `/api/v1/ampp/:id/cmed` | Dados AMPP + preço CMED (JOIN) |

### Uso — CLI de Importação CMED

```bash
# Importação padrão (header na linha 42)
go run cmd/cmed_import/main.go --source=Conformidade_202605.xlsx --date=2026-05-01

# Header em linha diferente
go run cmd/cmed_import/main.go --source=Conformidade_202605.xlsx --date=2026-05-01 --header-row=38

# Pular reindexação Meilisearch
go run cmd/cmed_import/main.go --source=Conformidade_202605.xlsx --date=2026-05-01 --skip-index
```

### Correções

- `dt_referencia::text` no cmed_repo.go — pgx não faz scan de DATE (OID 1082) em `*string`; cast para text no SQL
- `*time.Time` no sync_repo.go — mesmo fix para scan de dt_referencia
- Indentação YAML do docker-compose.yml corrigida (SYNC_ON_STARTUP, GIN_MODE, REDIS_HOST tinham indent=2 em vez de 4)

### Decisões de Arquitetura

- **D10**: Tabela CMED independente — sem FK para tabelas OBM, JOIN via `nu_sanreg`
- **D11**: Redis com graceful degradation — app funciona sem Redis (sem cache, query direta)
- **D12**: `nu_sanreg` (Registro Sanitário) é a chave de JOIN entre AMPP e CMED
- **D13**: `--header-row` (default 42) para mapeamento flexível de cabeçalhos XLSX

### Compatibilidade

- Sem breaking changes na API REST
- Todos os endpoints existentes permanecem inalterados
- Redis é opcional — API funciona normalmente sem ele (sem cache)
- Novos filtros `filter[tarja]` e `filter[registro]` na busca global são aditivos
- Migration `002_cmed_conformidade.sql` deve ser executada antes da primeira importação
