# Release Notes — v1.0.0

**Data:** 24/05/2026
**Status:** Released

## API OBM — Ontologia Brasileira de Medicamentos

Release inicial da API REST para consulta de dados da [Ontologia Brasileira de Medicamentos (OBM)](https://portal-obm.saude.gov.br/), seguindo o modelo dm+d (Dictionary of Medicine and Devices) do NHS adaptado para o Brasil.

---

### Funcionalidades

#### Endpoints de consulta

| Entidade | Endpoints | Destaques |
|----------|-----------|-----------|
| **VMP** | Listagem, por ID, detalhado | Detalhe inclui VTM, ingredientes, rotas, formas, classes ATC, catmats |
| **AMP** | Listagem, por ID, detalhado | Detalhe inclui VMP, fornecedor, ingredientes, rotas, condições de preservação |
| **VTM** | Listagem, por ID | Princípios ativos genéricos |
| **VMPP** | Listagem, por ID | Apresentações virtuais (quantidade) |
| **AMPP** | Listagem, por ID | Embalagens comerciais com código EAN-13 |
| **DCB** | Listagem, por ID | Denominações Comuns Brasileiras |
| **Ingredientes** | Listagem, por ID | Substâncias ativas com código CAS e DCB |
| **Fornecedores** | Listagem, por ID | Fabricantes com CNPJ e código de país |
| **Domínios** | Listagem por tipo, por tipo e ID | 32 tipos de classificação (forma, via, ATC, controle, etc.) |

#### Busca global

- Busca full-text via Meilisearch em VMPs, AMPs e Fornecedores
- Filtros por nome, código, fabricante, descrição e status ativo
- Filtro por tipo de entidade (`vmp`, `amp`, `supplier`)
- Relevância score nos resultados

#### Autenticação

- Login via `/auth/login` com username/senha
- Token JWT (HS256) com expiração configurável (padrão: 24h)
- Middleware de autenticação em todos os endpoints `/api/v1/`
- Compatibilidade com formato `Bearer <token>` e token direto (Swagger UI)

#### Paginação

- Todos os endpoints de listagem usam paginação cursor-based
- Limite configurável (padrão: 20, máximo: 100)
- Cursor codificado em base64 para paginação eficiente

#### Infraestrutura

- Docker Compose com PostgreSQL 16, Meilisearch v1.8 e API
- Health check público em `/health`
- Reindexação administrativa via `POST /api/v1/admin/reindex`
- Reindexação automática ao iniciar (`SYNC_ON_STARTUP=true`)
- Graceful shutdown com timeout de 5 segundos

#### Documentação e ferramentas

- Swagger UI integrado em `/swagger/index.html`
- Collection Postman com ambiente local pré-configurado
- README.md com documentação completa para usuários
- Guia de teste (TESTING.md)

---

### Correções incluídas

- Descrição corrigida de "Observatório de Medicamentos" para "Ontologia Brasileira de Medicamentos" (conforme portal oficial)
- Auth middleware aceita token com ou sem prefixo Bearer para compatibilidade com Swagger UI
- Porta do servidor alterada de 8080 para 8094
- Porta do PostgreSQL no host alterada de 5432 para 5433 (evita conflito com PostgreSQL local)
- Healthcheck do Meilisearch corrigido para usar curl em vez de wget
- Chave master do Meilisearch com tamanho mínimo de 16 bytes
- Syntax SQL corrigida na migration de inicialização
- Seed script corrigido para carregar .env via godotenv
