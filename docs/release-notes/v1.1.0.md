## CLI de Importação

Nova ferramenta de linha de comando para importar dados da OBM no PostgreSQL e reindexar o Meilisearch em um único comando.

### Funcionalidades

- **Pipeline completo de importação** — resolução de fonte, conversão MySQL→PostgreSQL, importação via streaming, validação, metadados e reindexação
- **Fontes aceitas** — ZIP (extrai `.sql` interno), SQL, SQL.GZ (gzip), URI `mysql://` (executa `mysqldump`)
- **Streaming via `io.Pipe`** — conversão e importação ocorrem em paralelo sem arquivo temporário em disco
- **Validação pós-importação** — contagem de registros por tabela e verificação de integridade referencial (VMP→VTM, AMP→VMP, AMP→Fornecedor)
- **Metadados** — tabela `obm_metadata` registra versão dos dados, data da importação, arquivo de origem e contagem de registros
- **Modos de operação** — `--convert-only`, `--reindex-only`, `--skip-index`, `--validate`, `--full`

### Uso

```bash
# Importação completa
go run cmd/import/main.go --source=portal-obm-20250530.zip

# Com validação
go run cmd/import/main.go --source=portal-obm-20250530.zip --validate

# Apenas converter
go run cmd/import/main.go --source=dump.sql --convert-only

# Apenas reindexar
go run cmd/import/main.go --reindex-only
```
